# Changelog

## 0.1.0 (2026-11-16)

First public version. Reads, downloads and a local mirror; people and face fixes; tags and ratings; albums (also
from rules); sharing by link and with DSM users, always expiring; folder create, rename, move and removal of empty
folders; photo moves and uploads; cleanup of the albums the tool created. No photo is ever deleted: an allow-list
of API calls, armed removals, never-overwrite modes, a journal of every write.
